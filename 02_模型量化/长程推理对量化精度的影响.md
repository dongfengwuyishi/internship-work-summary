# 长程推理对量化精度的影响

## 长上下文 Prefill

使用固定的约 8192 token Daily-Omni 输入，对比 bf16 和 AWQ 量化模型。误差主要在深层放大：AWQ-text 的 L00 平均 L2 约为 0.85，L16 为 18.84，L35 达到 544.65。

三种 AWQ 校准版本的 L35 分别约为：

- embed：528.89
- video：535.68
- text：544.65

校准方式能够影响长上下文误差，但三者差距远小于从浅层到深层的误差放大。

## 多轮 Decode

在 100 轮 teacher-forced decode 和 50 轮真实多模态输入中，量化模型的浅层 L2 通常约为 1，最后一层约为 540–790。GPTQ-text 通常偏差最大，GPTQ-embed 明显更接近 bf16。

随着 KV cache 增长，末轮误差有时高于首轮，但按多轮区间统计并没有稳定单调上升，同时存在少量 token 级 spike。因此更准确的结论是：长程推理会放大深层偏差并带来轮间波动，但不能简单认为误差会随轮数线性累积。

自由生成时分叉更加明显。50 轮实验中，相对 bf16 的平均 token 匹配率为：

- AWQ：30.2%
- GPTQ-embed：16.2%
- GPTQ-video：3.9%
- GPTQ-text：0.9%

该指标受解码分叉影响较大，只适合作为行为差异参考。

## 长任务准确率

LongBench 15 个任务宏平均中，bf16 为 31.16，AWQ-video 为 31.13，几乎无损；GPTQ-text 为 28.94，GPTQ-embed 为 26.71。代码和长文本任务对部分 GPTQ 版本更敏感。

Video-MME 全量结果中，bf16 为 68.81%，各量化版本为 66.93%–68.21%。按 long 视频拆分，AWQ-text 为 59.3%，bf16 为 57.8%，GPTQ-video 为 55.8%，不同模型存在小幅分化，但没有统一的“上下文越长、准确率必然越低”的排序。

## 结论

长程推理中的量化误差主要表现为深层 hidden-state 放大、轮间波动和自由生成分叉。数值误差与任务分数不是一一对应关系，应同时使用 hidden-state 诊断、LongBench 和长视频任务评测。
